# Images des Produits

## Structure
- laptop-dell.jpg : Image du laptop Dell Inspiron 15
- souris-logitech.jpg : Image de la souris Logitech
- clavier-rgb.jpg : Image du clavier mécanique RGB

## Format
- Taille : 400x300px (ratio 4:3)
- Format : JPG ou PNG
- Poids : Max 1MB par image
- Qualité : 80-90%

## Utilisation
Les images sont automatiquement affichées sur l'interface publique (/) 
si elles existent, sinon une icône par défaut est utilisée.
